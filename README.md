## Installation

```bash
# Clone repo
git clone https://github.com/francogabrieloliveros/project-mfs

cd project-mfs
```

```bash
# Install uv for Mac
brew install uv

# or

# Install uv for Fedora
sudo dnf install uv
```

```bash
# Install project dependencies
uv sync
```

## Running

```bash
# uv run main.py

uv run <file-name>
```

## Adding Packages

```bash
uv add <package-name>
```
